# EvenFall Lavender & Light Orange Themes for Visual Studio Code

## Overview

This extension provides two beautiful themes for Visual Studio Code: **EvenFall Lavender** and **EvenFall Light Orange**. Whether you prefer a calm, soothing lavender palette or a vibrant, warm light orange scheme, these themes enhance your coding experience with visually appealing colors and easy readability and protect your eyes from unexpected effects.

## Features

- **EvenFall - Lavender Theme**: A soft and calming theme that promotes focus and reduces eye strain. Ideal for long coding sessions.
- **EvenFall - Light Orange Theme**: A bright and cheerful theme that energizes your workspace and boosts creativity.

## Installation

1. Open Visual Studio Code.
2. Go to the Extensions view by clicking on the Extensions icon in the Activity Bar on the side of the window.
3. Search for `Lavender & Light Orange Themes`.
4. Click **Install** on the theme extension.

## Usage

1. After installation, press `Ctrl + K` followed by `Ctrl + T` to open the Theme Selection.
2. Choose either **Lavender Theme** or **Light Orange Theme** from the list.
3. Enjoy coding in your new beautiful theme!
